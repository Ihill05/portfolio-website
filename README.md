# Iysha Hillard - Portfolio

Personal 3D interactive portfolio for Iysha Hillard, Senior Analytics Specialist.

## Tech Stack

React 18 • TypeScript • Vite • Three.js • React Three Fiber/Drei/Cannon/Rapier • GSAP • WebGL

## Development

```bash
npm install
npm run dev
npm run build
```
